# Bloom - Studio di design

**Bloom** è il sito web ufficiale di uno studio creativo di design. Il progetto è una landing page professionale, completamente responsive, dotata di script interattivi e di una struttura organizzata per la gestione dei contenuti multimediali.

## Caratteristiche
* **Design Responsive:** Ottimizzato per layout desktop, tablet e smartphone grazie a fogli di stile dedicati.
* **Theme Toggle (Dark/Light):** Gestione dinamica del cambio tema tramite script JavaScript.
* **Interattività Avanzata:** Controllo delle finestre modali (es. richiesta preventivo) ed elementi dinamici tramite codice JS.
* **Media Dedicati:** Organizzazione pulita del progetto con una cartella centralizzata per tutte le immagini e le risorse multimediali.
* **Icone Vettoriali:** Integrazione con la libreria *Ionicons* per icone flessibili e moderne.

## Struttura del Progetto
Il progetto segue una struttura modulare e pulita:
```text
├── index.html          # Struttura semantica principale
├── assets/
│   ├── style.css       # Foglio di stile per layout, font e colori globali
│   ├── responsive.css  # Regole CSS e Media Queries per i dispositivi mobili
│   └── script.js       # Logica JavaScript per modali e cambio tema
└── media/              # Cartella dedicata esclusivamente a immagini e file multimediali
    ├── logo.png
    └── segnaposto.png  
```

## Tecnologie Utilizzate
* **HTML5:** Struttura semantica del sito (`<header>`, `<main>`, `<section>`).
* **CSS:** Stile avanzato, griglie fluide (Flexbox/Grid) e design adattivo.
* **JavaScript (JS):** Script per gestire l'interattività dell'utente (interruttore del tema e pulsante CTA).
* **Ionicons:** Icone esterne in formato SVG per arricchire l'interfaccia.
